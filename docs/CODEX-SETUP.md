# Try Day Club operator setup

Use the [current setup guide](CODEX-SETUP-SHAREABLE.md) for public rental tools
and authorized operator access. The operator login uses the email and
password for your Try Day Club operator account. Request access from the
administrator through the approved secure channel.

The public connector is `https://trydayclub-mcp.fly.dev/mcp`.
The operator connector is `https://trydayclub-mcp.fly.dev/ops/mcp`.
